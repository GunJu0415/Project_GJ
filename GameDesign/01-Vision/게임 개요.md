# 게임 개요

## 한 줄

**위에서 내려다보는 시점의 로그라이트 런앤건.** 마우스로 겨누고, 구르며 피하고, 죽으면 처음부터 다시 시작한다. 매 런마다 레벨업 때 고른 카드가 달라서 같은 캐릭터로 두 번 플레이해도 같은 빌드가 나오지 않는다.

## 정체성

| 축 | 결정 | 근거 |
|---|---|---|
| 장르 | 로그라이트 (회차제). 죽으면 런이 끝나고 성장이 사라진다 | 사망 → 허브 복귀 → 회차 카운트 증가가 이미 닫혀 있다 |
| 시점 | 탑다운. 카메라는 스프링암으로 고정 | 지형과 적 배치를 한눈에 보게 하는 구성 |
| 조작 | 이동은 키보드, **조준은 마우스**. 둘이 분리돼 있다 | 커서를 캐릭터의 지면 평면에 투영해 그 방향으로 회전 |
| 전투 리듬 | 좌클릭 홀드 연사 + 회피로 빠져나오기 | 누르고 있으면 무기 자체 발사 간격으로 계속 나간다 |
| 성장 | 런 안에서만. 레벨업마다 카드 3장 중 1택 | 레벨·경험치·스탯 보너스·먹은 카드가 전부 런 종료 시 사라진다 |
| 진행 | 방을 클리어하며 나아간다 (**미완성**) | 방 하나는 성립하지만 방과 방을 잇는 것이 아직 없다 |

## 조작 감각

이 게임이 무엇인지는 조작 설계에 가장 짙게 나타나 있다.

| 입력 | 동작 | 설계 의도 |
|---|---|---|
| 이동 키 | 8방향 이동 | 조준과 독립. 뒷걸음질하며 쏠 수 있다 |
| 마우스 | 캐릭터가 커서를 본다. 카메라도 커서 쪽으로 조금 끌려간다 | **겨누는 행위가 곧 시야 확보다.** 멀리 보려면 그쪽을 겨눠야 한다 |
| 좌클릭 (홀드) | 장착 무기 연사 | 발사 간격 판단이 무기 안 한 곳에만 있어 연사 편차가 없다 |
| 우클릭 (홀드) | 스킬 슬롯 1 — **누른 만큼 차징**, 떼면 발사 | 오래 누를수록 구체가 커지고 데미지가 오른다. 크기가 곧 진행도 표시다 |
| Q / F | 스킬 슬롯 2 / 3 | 슬롯은 준비됐지만 **넣을 스킬이 아직 없다** |
| 회피 | 8방향 구르기 | 구르는 동안 적과의 충돌을 무시한다 — 사실상 무적 프레임 |
| R | 재장전 | **MP를 소모한다** (아래) |
| 1 / 2 | 무기 슬롯 전환 | 무기를 2개 들고 다닌다 |
| E | 상호작용 | 아이템·무기·상자·포탈이 전부 같은 입력 |
| Tab | 인벤토리 (아이템 / 무기 / 스킬 3페이지) | 여는 동안 게임이 멈춘다 |

### 손맛에 관해 내린 판단

- **회피는 웬만하면 나간다.** 벽에 막혀도 회피를 취소하지 않고 거리만 줄인다. 벽을 등지고 있어도 최소한 방향 전환은 나가게 하려는 것이다.
- **차징은 최소치가 없다.** 톡 치면 작고 약한 구체, 꾹 누르면 크고 센 구체. "덜 찼으니 불발"이 없어서 **우클릭은 뗀 이상 항상 무언가를 한다.**
- **차징을 끊는 유일한 수단이 회피다.** 강한 한 방을 포기하고 몸을 뺄지 판단하게 만든다.

## 자원 하나가 두 곳에서 소비된다

이 게임에서 가장 특징적인 결정이다. **MP가 재장전과 스킬 양쪽에 쓰인다.**

```
MP ─┬─ 재장전   (탄약 1발당 MPCostPerAmmo)
    └─ 스킬     (떼는 순간 고정 소비)
```

MP가 모자라면 **채울 수 있는 만큼만 부분 재장전**이 된다. 그 결과 "지금 MP를 총알로 바꿀까, 큰 한 방으로 남겨둘까"가 전투 중 계속 반복되는 판단이 된다.

## 재미의 축

| 축 | 지금 성립하나 | 내용 |
|---|---|---|
| 조준·회피의 손맛 | O | 마우스 조준 + 무적 회피 + 연사. 가장 완성도가 높은 부분 |
| 자원 저글링 | O | MP 하나를 총알과 스킬이 나눠 쓴다 |
| 매 런 달라지는 빌드 | O (얇게) | 카드 3택 + 무기 2슬롯 + 스킬 3슬롯. **카드가 6장뿐이라 아직 체감되지 않는다** |
| 리스크와 리턴의 거래 | O (한 종류) | 악마 아이템: 최대 체력을 팔아 카드 선택을 산다 |
| 던전을 헤쳐나가는 긴장 | X | 방 하나는 되지만 이어지지 않는다. 클리어 조건도 없다 |
| 회차를 넘는 성장 | X | 영구 강화·세이브가 없다. 지금은 죽으면 정말 아무것도 안 남는다 |

## 한 판의 길이

**지금은 정해져 있지 않다.** 런을 끝내는 방법이 **사망뿐**이고 승리 조건이 없어서, 한 판의 길이는 "죽을 때까지"다.

성장 곡선으로만 역산하면 이렇다 (전부 임시 테스트 값):

| | 값 |
|---|---|
| 만렙 | 5 (`DT_CharacterStat`의 마지막 행) |
| 1 → 5 누적 필요 경험치 | 1500 |
| 적 1마리 보상 | 50 |
| 만렙까지 필요한 처치 수 | **30마리** |

즉 현재 데이터대로면 잡몹 30마리를 잡으면 성장이 끝나고 그 뒤로는 카드도 안 나온다. 이것은 밸런싱 결과가 아니라 검증용 값이므로, 진행 구조가 생긴 뒤에 다시 잡아야 한다. → [[레벨 곡선]]

## 무엇이 남고 무엇이 사라지나

로그라이트의 핵심 경계다. 지금은 **왼쪽만 있고 오른쪽이 비어 있다.**

| 런 안에서만 (죽으면 사라짐) | 회차를 넘어 남음 |
|---|---|
| 레벨, 경험치 | 누적 도전 횟수 (`RebirthCount`) — **저장이 없어 앱을 끄면 0** |
| 카드로 얻은 스탯 보너스 | (없음) |
| 획득한 무기·스킬 | (없음) |
| 인벤토리 | (없음) — `bPersistAcrossRuns` 필드만 있고 읽히지 않는다 |

이 초기화는 코드로 지우는 것이 아니라 **레벨을 다시 여는 순간 캐릭터가 새로 스폰되면서 저절로** 일어난다. 그래서 "무엇을 남길지"를 정하는 일은 아직 한 줄도 시작되지 않은 상태다.

## 아직 게임이 아닌 부분

정직하게 말하면, 지금 이것은 **전투와 성장이 완성된 샌드박스**다. 게임으로 성립하려면 다음이 필요하다.

- 방과 방을 잇는 구조 — 지금은 방 하나를 손으로 놓아야 한다
- 런을 이기는 방법 — 보스도, 스테이지도, 승리 조건도 없다
- 회차를 넘는 무언가 — 다시 시작할 이유가 "재밌어서" 말고는 없다

## 미정

- **한 런은 몇 분짜리인가?** 방 몇 개, 스테이지 몇 개를 지나면 끝나는가?
- **런을 이긴다는 것은 무엇인가?** 마지막 보스인가, 정해진 층수 돌파인가, 무한 모드인가?
- **회차를 넘어 무엇이 남는가?** 영구 강화 재화인가, 해금인가, 아니면 아무것도 안 남는 순수 로그라이크인가?
- **골드(화폐)는 런을 넘어 남는가?** 이 답이 상점과 영구 강화의 설계를 동시에 결정한다.
- **캐릭터가 여러 명인가?** 지금은 1종이고 직업/클래스 개념이 없다. 카드 태그 밀어주기(`Tree.Fire` 등)는 "직업 카드"를 상정하고 만들어졌지만 그 주체가 없다.
- **근접 전투를 실제로 할 것인가?** 콤보 몽타주 로직은 있는데 히트 판정이 없고, 근접 무기 클래스 자체가 없다. "런앤건"으로 갈지 "핵앤슬래시"를 섞을지가 아직 안 정해졌다.
- **적은 몇 종이 필요한가?** 현재 정의된 적은 근접 추격형 1종뿐이다.
