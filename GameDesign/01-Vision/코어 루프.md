# 코어 루프

플레이어가 반복하는 사이클을 크기 순으로 넷으로 나눈다. **아래로 갈수록 주기가 길고, 아래로 갈수록 비어 있다.**

| 루프 | 주기 | 상태 |
|---|---|---|
| 1. 전투 루프 | 초 | 완성 |
| 2. 성장 루프 | 분 | 완성 |
| 3. 방 루프 | 분 | **반쪽** — 방 하나는 되지만 이어지지 않는다 |
| 4. 런 루프 | 판 | **반쪽** — 지는 것만 있고 이기는 것이 없다 |
| 5. 메타 루프 | 판 사이 | **없음** |

---

## 1. 전투 루프 (초 단위)

```
겨눈다 ──> 쏜다 ──> 탄약이 떨어진다 ──> 재장전(MP 소모)
   ^                    |                     |
   |                    v                     v
   └──── 회피로 빠져나온다 <──── 적이 붙는다 ──┘
                        |
                        └─> MP를 아껴 차징 스킬로 한 방
```

이 루프의 긴장은 **MP 하나를 재장전과 스킬이 나눠 쓴다**는 데서 나온다. 총알로 바꿀지 큰 한 방으로 남길지가 매 교전에서 반복된다.

**완성돼 있다.** 조준·연사·회피·재장전·차징 스킬이 전부 동작한다. → [[전투]], [[스킬]]

---

## 2. 성장 루프 (분 단위)

```
적을 처치한다 ──> 경험치 ──> 레벨업 ──> 카드 3장 중 1택 ──> 강해진다
      ^                                                        |
      └────────────────────────────────────────────────────────┘
```

| 규칙 | 내용 |
|---|---|
| 경험치 | 적마다 데이터로 정한 값. 죽인 사람에게만 간다 |
| 레벨업 | 여러 레벨이 한 번에 올라도 카드 선택이 그만큼 대기열에 쌓인다 |
| 회복 아님 | 최대치가 오른 만큼만 현재 HP/MP에 더해진다. 레벨업이 위기 탈출 수단이 되면 안 되기 때문 |
| 카드 | 게임을 멈추고 3장을 띄운다. **스킵·리롤이 없어 반드시 하나를 골라야 한다** |
| 만렙 | 데이터 테이블의 마지막 행. 지금은 5레벨 = 카드 4번 |

**레벨업 말고도 카드가 나오는 길이 하나 더 있다** — 악마 아이템이 최대 체력을 받고 카드 선택을 준다. 카드 지급 입구가 공개 함수 하나로 모여 있어서, 앞으로 보스 처치·스테이지 클리어도 같은 입구를 쓴다.

**완성돼 있다.** 단, 카드가 6장(검증용 임시 데이터)뿐이라 "매번 다른 빌드"가 아직 체감되지 않는다. → [[카드 성장]]

## 3. 방 루프 (분 단위) — 반쪽

```
방에 들어간다 ──> 적·아이템·상자가 랜덤하게 채워져 있다
       |
       v
   전멸시킨다 ──> 출구가 열린다 ──> [ 다음 방 ]  ← 여기가 비어 있다
```

방 하나 안에서 일어나는 일은 전부 된다.

| 되는 것 | 내용 |
|---|---|
| 랜덤 구성 | 적 수·조합, 바닥 아이템, 상자 등장 여부를 매번 다시 뽑는다 |
| 전멸 판정 | 방이 자기가 스폰한 적의 죽음만 센다 |
| 출구 개폐 | 들어가면 막히고, 전멸시키면 열린다 |
| 방의 역할 | 전투방·보물방·회복방·보급방(악마방)이 **전부 같은 방 클래스 + 다른 데이터 행**으로 성립한다 |

**비어 있는 것.**

| 빈 칸 | 지금 상태 |
|---|---|
| 방과 방을 잇는 것 | 레벨에 방을 손으로 하나 놓아야 한다. 절차적 배치가 없다 |
| 방 진입 트리거 | 방은 게임 시작과 동시에 전부 채워진다. "들어가면 채워진다"가 아니다 |
| 보스방 | 클래스 자리만 비어 있다. 넘길 스테이지가 없어서 안 만들었다 |
| 문 연출 | 블로커가 그냥 사라진다 |

→ [[던전과 방]]

## 4. 런 루프 (한 판) — 반쪽

```
[허브]  포탈에 상호작용
   |
   v
[전투 레벨]  싸운다 · 성장한다
   |
   ├─ 죽는다 ──> 게임오버 화면 ──> 허브로 복귀 (도전 횟수 +1)
   |                                    |
   └─ 이긴다 ──> ?????  ← 존재하지 않는다
                                        v
                                    [허브]  다시 포탈
```

| 규칙 | 내용 |
|---|---|
| 런의 끝 | **사망뿐이다.** 승리 경로가 설계상 존재하지 않는다 |
| 초기화 | 레벨을 다시 여는 순간 캐릭터가 새로 스폰되어 저절로 된다. 지우는 코드가 없다 |
| 도전 횟수 | 사망 시점 한 곳에서만 오른다. 게임오버 화면이 표시하는 값이 곧 "방금 끝난 도전의 번호" |
| 허브 | 안전 지대. **포탈 하나 말고 아무것도 없다** |

**비어 있는 것.**

| 빈 칸 | 지금 상태 |
|---|---|
| 클리어(승리) 조건 | 없다. 런을 끝내는 함수가 종료 사유조차 받지 않는다 |
| 스테이지 진행 | 전투 레벨이 하나뿐이고 그 안에서 계속 논다 |
| 회차 인계 규칙 | "무엇이 남는가"가 정해지지 않았다. 아이템 데이터에 필드만 있고 읽히지 않는다 |

→ [[런 루프]]

## 5. 메타 루프 (판과 판 사이) — 없음

로그라이트가 "한 번 더"를 만드는 자리인데, 통째로 비어 있다.

| 있어야 할 것 | 지금 |
|---|---|
| 세이브 | 없다. 도전 횟수조차 앱을 끄면 0으로 돌아간다 |
| 영구 강화 | 없다. 별도 재화 + 별도 저장소로 만들기로만 정해져 있다 |
| 해금 | 없다 |
| 상점 | 없다. 화폐 시스템이 먼저이고, 바닥에 아이템을 까는 대신 상점 NPC와 상호작용하기로 정해져 있다 |

**지금 다시 시작할 이유는 "전투가 재밌어서" 하나뿐이다.**

---

## 방 시스템이 끼어들 자리

방 시스템이 막 생겼기 때문에, 루프 3과 4 사이가 앞으로 이렇게 바뀐다.

**지금**

```
포탈 ──> 전투 레벨 (방 하나) ──> 사망 ──> 허브
```

**방과 진행이 붙은 뒤 (예정)**

```
포탈 ──> 방 ──> 전멸 ──> 출구 ──> 다음 방 ──> ... ──> 보스방 ──> 다음 스테이지
                                                          |
                                                          └─> 런 클리어
```

이때 새로 결정해야 하는 것:

- 방 클리어 자체가 보상을 주는가? (카드 지급 입구는 이미 열려 있다)
- 방을 몇 개 지나면 보스인가?
- 출구가 여러 개일 때 플레이어가 경로를 고르는가? (지금 방에는 문이 북쪽 하나뿐이다)
- 던전 전체를 한 번에 채우면 먼 방의 적까지 처음부터 살아 움직인다 — 거리 기준으로 AI를 꺼야 한다

## 루프 전체에서 비어 있는 칸 요약

| # | 빈 칸 | 어느 루프 | 왜 중요한가 |
|---|---|---|---|
| 1 | 런 클리어 조건 | 4 | 이기는 방법이 없으면 "도전"이 성립하지 않는다 |
| 2 | 방과 방을 잇는 진행 구조 | 3 | 전투와 성장이 향할 목표가 없다 |
| 3 | 회차 인계 규칙 | 4 → 5 | 무엇을 남길지가 세이브의 전제다 |
| 4 | 세이브 | 5 | 없으면 회차 자체가 세션 안에서만 존재한다 |
| 5 | 영구 강화 | 5 | 다시 시작할 이유 |
| 6 | 카드 물량 | 2 | 6장으로는 빌드가 갈리지 않는다 |
| 7 | 적 종류 | 1 | 1종으로는 전투 상황이 달라지지 않는다 |

## 미정

- **방 클리어가 보상을 주는가?** 준다면 카드인가, 아이템인가, 화폐인가?
- **한 스테이지는 방 몇 개인가?** 그리고 몇 스테이지가 한 런인가?
- **플레이어가 경로를 고르는가?** (아이작·하데스처럼 다음 방의 종류를 보고 고르는 구조인가)
- **회복방·보급방은 얼마나 자주 나와야 하는가?** 클래스와 데이터 행은 준비됐지만 등장 빈도 규칙이 없다.
- **런 클리어 후 어디로 가는가?** 허브로 돌아가는가, 다음 난이도로 이어지는가?
- **죽었을 때 회차 카운트 말고 무엇을 보여줘야 하는가?** (도달 층수, 처치 수, 빌드 요약 같은 결과 화면이 없다)
