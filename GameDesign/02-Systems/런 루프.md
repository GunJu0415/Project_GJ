# 런 루프

한 판(런)이 어떻게 시작해서 어떻게 끝나는가. 그리고 끝났을 때 무엇이 남는가.

## 한 바퀴

```
허브  →  포탈에 상호작용  →  전투 레벨
                                 │
                        경험치 · 레벨업 · 카드
                                 │
                              체력 0
                                 │
                        (약 2초)  게임오버 화면
                                 │
                        "허브로 돌아가기"
                                 │
                               허브  →  다시 시작
```

| 단계 | 무슨 일이 일어나나 |
|---|---|
| 허브 | 적도 위험도 없는 안전지대. 포탈 하나만 있다 |
| 런 시작 | 포탈에 다가가 상호작용하면 전투 레벨로 넘어간다 |
| 전투 | [[던전과 방]]의 방에서 [[전투]]하고, 적을 잡아 레벨을 올리고 [[카드 성장]]으로 강해진다 |
| 사망 | 체력이 0이 되면 움직임과 충돌이 꺼진다. 게임을 멈추지는 않는다 |
| 게임오버 | 약 2초 뒤 화면이 뜬다. **이 시점에 회차 카운트가 오른다** |
| 허브 복귀 | 버튼을 누르면 허브로 돌아간다. 캐릭터는 완전히 처음 상태다 |

**사망해도 게임을 멈추지 않는다.** 적은 계속 움직이지만 플레이어의 충돌이 이미 꺼져 있어 무해하다. 일시정지와 입력 모드를 동시에 건드리면 포커스가 새는 문제를 여러 번 겪었기 때문에, 여기서는 입력만 UI로 넘기고 정지는 걸지 않는다.

**죽자마자 화면이 뜨지 않고 2초를 기다린다.** 죽는 순간이 보이지 않으면 왜 죽었는지 알 수 없다.

## 회차 카운트

플레이어가 지금까지 도전한 **누적 횟수**다. 특정 세션의 값이 아니라 계속 쌓이는 값으로 설계되었다 — "N번째 도전"이라는 지표로 그대로 쓸 수 있다.

- **오르는 시점은 사망 한 곳뿐이다.** 새 런을 시작할 때는 오르지 않는다. 이렇게 해야 게임오버 화면이 표시하는 숫자가 곧 "방금 끝난 도전의 번호"가 된다.
- 게임오버 화면을 거치든 안 거치든 정확히 한 번만 오른다.

**지금은 앱을 끄면 0으로 돌아간다.** 저장이 아직 없다. 설계상 이 값은 세이브에 들어갈 1순위이고, 그때가 되어야 "게임을 껐다 켜도 이어지는 도전 횟수"가 완성된다.

## 런 안에서의 성장

런은 **들어갈 때보다 강해져서 나오는 것**이 성립해야 성립한다. 그 축이 경험치와 레벨이다.

| | 규칙 |
|---|---|
| 경험치 획득 | 적을 죽이면 그 적에 정해진 값만큼 받는다. **실제로 죽인 사람에게만** 간다 |
| 적이 주는 양 | 적마다 손으로 정한 값이다. 체력이나 공격력에서 유도하지 않는다 |
| 필요 경험치 | "이 레벨에서 다음 레벨까지" 필요한 양이다. 누적 총량이 아니다 |
| 넘친 경험치 | 다음 레벨로 이월된다. 한 번의 킬로 여러 레벨이 오를 수 있다 |
| 만렙 | [[레벨 곡선]] 표의 마지막 행. 코드에 박힌 상한이 없어서 행을 추가하면 만렙이 늘어난다 |
| 레벨업 보상 | 새 스탯 + **카드 3장 중 1택** ([[카드 성장]]) |

**적이 주는 경험치를 체력에서 유도하지 않는 이유**는 밸런스 축이 서로 묶이기 때문이다. 어떤 적을 좀 더 단단하게 만들려고 체력만 올렸는데 경험치까지 따라 올라가면 의도하지 않은 성장 속도 변화가 생긴다. "체력만 많고 안 위험한 샌드백"이나 "약한데 성가신 견제형" 같은 적은 공식으로 표현할 수 없다.

### 레벨업은 완전 회복이 아니다

레벨이 오르면 **최대 체력이 오른 만큼만** 현재 체력에 더해진다. 체력 30/100에서 최대 체력이 120이 되면 **50/120**이지 120/120이 아니다.

완전 회복으로 하면 **잡몹 하나 잡는 것이 게임 최고의 회복 수단**이 된다. 위기에 몰렸을 때 도망칠지 싸울지 고민할 이유가 사라지고, 로그라이크에서 체력 관리의 긴장이 통째로 없어진다. 회복은 회복 수단(아이템·회복방)이 담당해야지 성장이 겸하면 안 된다.

성장의 이득은 그대로 주되 **위험한 상태는 위험한 채로 남긴다** — 이게 이 규칙 하나가 하는 일이다.

## 런이 끝나면 무엇이 남나

| | 런이 끝나면 |
|---|---|
| 레벨·경험치 | 사라진다 |
| 고른 카드·스탯 보너스 | 사라진다 |
| 무기·스킬 | 사라진다 |
| 인벤토리 | 사라진다 |
| 회차 카운트 | 남는다 (단, 앱을 끄면 사라진다 — 저장 미구현) |

**이 초기화는 코드로 하는 것이 아니라 저절로 되는 것이다.** 레벨을 다시 여는 순간 캐릭터가 새로 만들어지므로 모든 것이 처음 값으로 돌아간다. "일부만 넘긴다"는 규칙이 생기면 그때 예외를 만들면 되고, 그때도 이 자연 초기화가 올바른 기본값이다.

**회차를 넘어 남는 성장은 아직 하나도 없다.** 아이템 데이터에 "런을 넘어 남는가"를 표시하는 칸이 있지만 아무도 읽지 않는다. 영구 강화는 카드와 완전히 별개의 축 — 별도 재화로 찍는 특성 — 으로 만들 예정이고, 두 축을 섞지 않기로 했다. 섞으면 나중에 "이번 런의 성장"과 "영구 성장"을 분리할 수 없게 된다.

```
런 안의 성장   경험치 · 레벨 · 카드      →  죽으면 사라진다
영구 성장      별도 재화로 찍는 특성      →  아직 없다
```

## 런은 사망으로만 끝난다

**승리 조건이 없다.** 던전을 끝까지 갔다는 상태가 정의되어 있지 않고, 정의할 대상인 스테이지 진행 자체가 없다([[던전과 방]]). 지금 플레이어가 런을 끝내는 방법은 죽는 것뿐이다.

이건 임시 상태이지 의도된 최종 설계가 아니다. 로그라이크에서 "끝까지 가서 이긴다"는 목표가 없으면 강해지는 이유가 없다 — 강해지는 것 자체가 목적이 되어버린다. [[카드 성장]]과 [[스킬]]이 향할 목표가 비어 있는 셈이다.

## 허브

지금 허브에 있는 것은 **런 시작 포탈 하나뿐이다.** 상점도, 영구 강화도, 다른 NPC도 없다. 허브에는 위험 요소가 없어서 여기서 죽는 경로 자체가 존재하지 않는다.

허브가 존재하는 이유는 지금 당장의 기능이 아니라 **경계를 만들기 위해서다.** "런 안"과 "런 밖"이 물리적으로 나뉘어 있어야 무엇이 회차를 넘어 남는지, 영구 강화를 어디서 찍는지, 무엇을 저장하는지를 나중에 정할 자리가 생긴다.

## 미정

- **런에 승리 조건을 어떻게 줄 것인가?** 스테이지 N개를 클리어하면 끝인가, 최종 보스를 잡으면 끝인가, 끝없이 이어지고 기록을 남기는가?
- 승리로 끝난 런과 사망으로 끝난 런의 **보상이 다른가**? 회차 카운트는 둘 다 오르는가?
- **회차를 넘어 무엇이 남는가?** 지금 정해진 것이 하나도 없다. 후보는 영구 재화, 해금된 무기·카드 풀, 영구 특성 트리, 도감 정도다
- 영구 재화를 쓴다면 **런 안에서 쓰는 돈과 같은 것인가 다른 것인가?** (상점 화폐가 런을 넘어 남는지가 여기서 갈린다)
- 사망 시 **가지고 있던 것 일부를 가져올 수 있는가**? "런을 넘어 남는" 아이템 칸을 실제로 쓸 것인가?
- 런 한 판의 **목표 플레이 시간**은 얼마인가? 이 값이 정해져야 스테이지 개수·레벨 곡선·경험치 양이 서로 맞는지 판단할 수 있다
- 한 런에서 도달하는 **목표 레벨**은 몇인가? 지금 만렙은 표의 행 개수일 뿐 의도된 값이 아니다
- 런 도중 **자발적으로 포기하고 허브로 돌아가는** 수단이 필요한가? 있다면 그것도 회차로 세는가?
- 게임오버 화면에 **런 요약**(처치 수, 도달 레벨, 고른 카드)을 보여줄 것인가?
