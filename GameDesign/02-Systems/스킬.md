# 스킬

우클릭을 누르고 있으면 손끝에 구체가 맺히고 점점 커진다. 떼면 날아간다. 오래 모을수록 크고 세지만, 그동안 할 수 있는 것은 걷는 것과 구르는 것뿐이다.

관련 문서: [[전투]] · [[카드 성장]] · [[스킬 목록]] · [[아이템과 인벤토리]]

---

## 슬롯 3개 = 키 3개

| 슬롯 | 키 |
|---|---|
| 0 | 우클릭 |
| 1 | Q |
| 2 | F |

**슬롯 번호와 키가 1:1로 고정되어 있다.** 그래서 "어느 슬롯에 넣을까"는 곧 "어느 키에 놓을까"와 같은 질문이 된다. 플레이어에게는 슬롯이라는 개념이 따로 보이지 않고, 키 배치만 보인다.

스킬은 세 개가 **항상 활성**이다. 무기처럼 "장착 전환"이 없다. 그래서 인벤토리의 스킬 칸을 클릭해도 아무 일이 일어나지 않는다 — 거기서 할 수 있는 것은 자리를 바꾸는 드래그뿐이다.

## 차징

```
비율     = 누른 시간 / 최대 차징 시간   (0 ~ 1)
배율     = 1 + (최대 배율 - 1) × 비율
구체 크기 = 기본 크기 × 배율
데미지    = 기본 데미지 × 배율  (그 뒤 스킬 공격력·치명타 계산)
```

**크기와 데미지가 같은 배율로 함께 커진다.** 화면에 보이는 구체의 크기가 곧 그 구체가 얼마나 센지다. 별도의 게이지 UI를 두지 않은 이유도 이것 — 구체 자체가 진행도 표시다.

### 뗀 이상 항상 나간다

"최소 차징 미만이면 불발" 같은 규칙은 **두지 않았다.** 짧게 톡 치면 작고 약한 구체, 꾹 누르면 크고 센 구체가 나갈 뿐이다.

이유는 입력이 씹힌 느낌을 없애기 위해서다. 우클릭을 뗐는데 아무 일도 일어나지 않으면 플레이어는 그것을 자기 선택이 아니라 고장으로 받아들인다. **차징을 무효로 만드는 유일한 경로는 회피이고, 그건 플레이어가 의도적으로 고른 취소다.**

### 차징 시간이 0인 스킬은 즉발이다

최대 차징 시간이 0으로 설정된 스킬은 **누르는 순간** 나간다(배율 1.0 고정). 뗄 때까지 기다리게 하면 차징도 없는데 손을 떼야 발동하는 이상한 감각이 된다.

### MP와 쿨타임은 뗄 때 고정값

차징을 얼마나 했든 **소비되는 마나와 들어가는 쿨타임은 같다.**

차징률에 비례시키는 쪽이 언뜻 공평해 보이지만, 그러면 **약한 구체를 연타하는 것이 최적해가 될 수 있다.** 그 균형을 다시 잡으려면 쿨타임까지 함께 조정해야 하고, 조정 변수가 하나에서 둘로 늘어난다. 고정값이면 "한 번의 발사를 얼마나 알차게 쓸 것인가"만 남는다.

MP는 [[전투|재장전]]도 쓰는 자원이다. 스킬 한 방과 탄창 한 번이 같은 통에서 나온다.

## 스킬 공격력은 평타와 별개 스탯이다

데미지 공식 자체는 평타와 같은 것을 쓰되, 공격력 자리에 들어가는 스탯이 다르다.

| | 쓰는 스탯 |
|---|---|
| 평타(무기) | 공격력 |
| 스킬 | **스킬 공격력** |
| 치명타 확률 · 배율 | **공유** |

나눈 이유는 **평타 특화와 스킬 특화 빌드가 갈리게 하기 위해서다.** [[카드 성장|카드]]로 한쪽만 올리는 선택이 실제 의미를 갖는다.

치명타를 나누지 않은 이유는 반대다. 스킬 전용 치명타 스탯까지 만들면 스탯이 두 벌이 되는데, 그걸 정당화할 만한 설계 요구가 아직 없다. **나눌 이유가 생기기 전에 나누지 않는다.**

## 차징 중에 할 수 있는 것

| 동작 | 차징 중 |
|---|---|
| 이동 | 가능 — **속도 감소 없음** |
| 회피 (Shift) | 가능 → **차징 취소** |
| 인벤토리 (Tab) | 가능 → **차징 취소 후 열림** |
| 좌클릭 평타 | 무시 |
| 재장전 (R) | 무시 |
| 무기 스왑 (1·2) | 무시 |

**차징을 끊는 유일한 전투 행동이 회피다.** "강한 한 방을 포기하고 구를 것인가"라는 판단이 매번 성립한다. 이것이 차징의 실제 비용이다.

**이동 속도를 깎지 않는다.** 회피 말고 아무것도 못 하는 것만으로 충분한 대가다. 속도까지 깎으면 짧게 톡 치는 약한 발사조차 위험 부담이 생겨서, 플레이어가 우클릭을 아예 안 쓰게 된다.

회피와 인벤토리를 다르게 다룬 이유가 있다. 회피는 전투 행동이라 "차징을 포기했다"가 판단으로 성립한다. 인벤토리는 전투 행동이 아니라 하던 걸 그만두고 메뉴를 여는 조작이라, 눌렀는데 안 열리면 그냥 고장으로 보인다. **그래서 인벤토리는 막지 않고, 대신 차징을 먼저 끈다.**

> 차징 취소는 회피가 **실제로 나갔을 때만** 일어난다. 공격 중이라 회피가 씹힌 상황에서 차징만 날아가면 플레이어는 아무 이유 없이 손해를 본다.

## 관통

스킬 구체는 적을 뚫고 지나갈 수 있다.

| 설정값 | 의미 |
|---|---|
| 0 | 1명 맞히고 소멸 |
| 1 | 2명 |
| -1 | **무한** — 사거리를 다 날아가야 사라진다 |

**같은 적을 두 번 때리지 않는다.** 큰 구체는 한 적의 몸 안에 여러 프레임 머무르기 때문에, 이걸 막지 않으면 프레임마다 재타격이 들어가 사실상 즉사기가 된다. 한 번 발사된 구체는 자기가 맞힌 적을 기억한다.

관통은 **적만 통과한다.** 벽은 여전히 막는다.

## 스킬은 카드로만 얻는다

스킬을 주는 [[카드 성장|카드]]를 고르는 것이 유일한 획득 경로다. 상점도 드랍도 없다.

```
스킬 카드 선택
 ├ 빈 슬롯이 있으면 → 첫 빈 슬롯에 바로 넣는다 (묻지 않는다)
 └ 세 슬롯이 다 찼으면 → "어느 스킬을 버릴지" 고르는 2단계 화면
```

빈 슬롯이 있을 때 묻지 않는 것은 클릭만 늘리기 때문이다. 이건 [[전투|무기]] 획득과 같은 규칙이다.

**교체 화면은 곧 키 선택 화면이다.** 슬롯 0/1/2가 우클릭/Q/F이므로, 선택지에는 스킬 이름과 함께 그 키가 같이 보인다(`우클릭 — 파이어볼을 버리고 교체`). 플레이어는 "무엇을 버릴지"와 "새 스킬을 어디에 놓을지"를 한 번에 정한다.

카드 화면이 여러 번 겹쳐도(연속 레벨업, [[아이템과 인벤토리|악마 아이템]]과 동시 발생) 선택권은 대기열에 쌓여 하나도 사라지지 않는다.

## 화면 표시

### HUD — 아이콘 3개

체력·마나·경험치 바 아래에 스킬 아이콘 세 개가 나란히 붙는다.

| 상태 | 표시 | 왜 |
|---|---|---|
| 쿨타임 | **덮개가 걷힌다** | 남은 시간이 면적으로 보인다 |
| MP 부족 | **아이콘이 파래진다** | 회색이 아니라 파랑이라 "쿨타임이 아니라 마나 문제"가 구분된다 |
| 빈 슬롯 | 아이콘만 숨기고 **키 라벨은 남긴다** | "F 자리가 비어 있다"를 알 수 있다 |

**두 표시는 서로 독립이다.** 쿨타임과 MP 부족이 동시에 걸려도 서로를 덮지 않는다.

**"쓸 수 있어 보이는데 눌러도 안 나가는" 상태를 만들지 않는다.** 화면이 판단하는 조건과 실제로 발사되는 조건이 같은 판정을 쓴다. 나중에 "MP 소모 감소" 같은 효과가 붙어도 둘이 어긋나지 않는다.

### 안 나갈 때는 이유를 남긴다

쿨타임·MP 부족·빈 슬롯으로 발동이 막히면 로그에 이유가 찍힌다. 플레이어에게 보이는 것은 아니고 개발 중 원인 추적용이다. 조용히 실패하면 데이터를 건드린 뒤 안 나가기 시작했을 때 원인을 찾는 데 한참 걸린다 — 실제로 그렇게 시간을 썼다.

### 인벤토리 — 드래그로 키 배치 바꾸기

인벤토리 세 번째 페이지가 스킬 페이지다. 칸 세 개(우클릭/Q/F)가 있고, **아이콘을 다른 칸으로 끌어다 놓으면 자리가 바뀐다.** 파이어볼을 우클릭에서 Q로 옮기는 것이 그대로 키 재배치다.

**자리를 바꿀 때 쿨타임도 같이 따라간다.** 이걸 놓치면 "스킬을 쓰고 인벤토리를 열어 자리를 옮기면 쿨타임이 사라지는" 초기화 수단이 된다.

반대로 카드로 새 스킬을 받을 때는 쿨타임을 **0으로 시작**한다. 없던 스킬이 새로 들어오는 것이라 물려받을 쿨타임이 없고, 교체가 손해가 되어서도 안 된다. **자리 교환과 신규 획득은 다른 동작이다.**

인벤토리에서 자리를 바꾸면 창을 닫았을 때 HUD도 이미 바뀌어 있다. 두 화면이 같은 신호를 듣는다.

### 차징 구체 미리보기

차징 중에는 총구 앞에 실제로 날아갈 구체가 나타나 발사될 크기까지 커진다.

- **모양은 실제로 발사되는 구체에서 그대로 가져온다.** 미리보기용 데이터를 따로 두면 언젠가 둘이 어긋나고, 고칠 때까지 아무도 모른다.
- **크기 공식도 발사와 같다.** 손을 떼는 순간 크기가 변하지 않는다.
- **총구에 붙어 있다.** 조준으로 캐릭터가 돌면 구체도 같이 돈다.
- 미리보기를 못 그리는 경우에도 **발사는 정상 동작한다.** 시각 요소가 게임플레이를 막으면 안 된다.

## 미정

- Q와 F에 무엇을 넣는가? 세 슬롯이 서로 다른 역할(광역 / 이동기 / 생존기)을 맡는 그림인가, 아니면 전부 공격기이고 계열만 다른가? → [[스킬 목록]]
- 지속형 스킬은 무엇을 하는가? "항상 켜져 있는 효과"라면 [[카드 성장|카드 스탯 보너스]]와 어떻게 구분되는가?
- 쿨타임 감소를 어디에 붙이는가? 스킬 쿨타임에만인가, 회피나 다른 것에도 걸리는가?
- 차징을 강제로 유지시키는(놓지 못하게 하는) 상황이 필요한가? 지금은 언제든 뗄 수 있고 회피로만 취소된다.
- 스킬에 사거리 제한이 있는 것이 맞는가? 관통 무한 + 사거리 소멸이 현재 규칙인데, 화면 밖으로 나간 구체가 계속 날아가는 것이 의도인가?
- 스킬 획득이 카드로만인 것이 최종인가? 보물 상자나 [[아이템과 인벤토리|악마 아이템]]에서 스킬이 나오는 경로가 필요한가?
- 같은 스킬을 두 번 얻으면 어떻게 되는가? 지금은 교체 화면이 뜬다 — 강화(레벨 2)가 되는 편이 자연스럽지 않은가?
- MP 자연 재생이 없는데, 스킬 세 개를 다 갖춘 상태에서 마나가 실제로 감당되는가? [[전투|재장전]]과 같은 통을 쓴다.
