# 무기

플레이어가 손에 드는 것. 지금 존재하는 무기는 **소총 한 자루**뿐이고, 무기 타입도 **원거리 하나**뿐이다.

> `DT_WeaponStat`에는 행이 하나(`1`)만 있다. 아래 수치는 그 행의 실제 값이며 **임시 테스트 값**이다.

관련 문서: [[전투]] · [[데미지 공식]] · [[아이템과 인벤토리]] · [[카드 목록]]

## 무기 데이터가 조절하는 것

무기 하나는 데이터 표의 행 하나다. 각 항목이 무엇을 바꾸는지:

| 항목 | 무엇을 조절하는가 |
|---|---|
| 기본 데미지 | 한 발이 주는 데미지. 여기에 플레이어 공격력이 배율로 곱해진다 |
| 투사체 속도 | 총알이 날아가는 속도 |
| 사거리 | 이 거리를 날아가면 총알이 스스로 사라진다 |
| 발사 간격 | 이 시간마다 최대 한 발. **실질적인 연사 속도** |
| 탄창 크기 | 재장전 없이 쏠 수 있는 발수 |
| 재장전 시간 | 재장전 몽타주가 없을 때 쓰이는 대체 시간 |
| 발당 MP 소모 | 재장전할 때 **실제로 채워지는 발수 × 이 값**만큼 MP를 쓴다 |
| 공격 속도 배율 | **현재 코드에서 안 읽힌다.** 연사 속도는 발사 간격이 담당한다 |
| 메시 / 공격·재장전·교체 몽타주 / 아이콘 | 겉모습과 애니메이션 |

**탄약이 MP를 먹는 구조가 이 게임 무기의 핵심 제약이다.** 총알은 공짜가 아니고, 재장전이 곧 자원 소모다. 그래서 MP는 스킬 전용 자원이 아니라 **사격과 스킬이 경쟁하는 공용 자원**이다 (→ [[전투]]).

## 현재 존재하는 무기

| 무기 | 데이터 행 | 타입 | 상태 |
|---|---|---|---|
| 소총 | `DT_WeaponStat`의 행 `1` | 원거리 | 유일하게 존재하는 무기. 시작 무기이자 카드 보상 |

### 소총의 실제 값

| 항목 | 값 |
|---|---:|
| 기본 데미지 | 15 |
| 공격 속도 배율 | 1.0 (미사용) |
| 투사체 속도 | 3000 |
| 사거리 | 2000 |
| 발사 간격 | 0.4초 |
| 탄창 크기 | 30발 |
| 재장전 시간 | 1.5초 |
| 발당 MP 소모 | 1 |

### 이 숫자들이 실제로 무엇을 뜻하는가

| 계산 | 결과 |
|---|---|
| 초당 발사수 | 0.4초 간격 → **초당 2.5발** |
| 레벨 1 기준 한 발 데미지 | 15 × (1 + 10/100) = **16.5** |
| 레벨 1 기준 초당 데미지 | 약 **41** |
| 탄창 하나를 비우는 시간 | 30발 × 0.4초 = **12초** |
| 탄창 하나로 죽일 수 있는 잡몹 | 체력 100 기준 약 **4마리** |
| 완전 재장전 비용 | 30발 × MP 1 = **MP 30** (레벨 1 최대 MP 50) |
| 투사체가 사거리 끝까지 가는 시간 | 2000 / 3000 = 약 0.67초 |

**레벨 1 최대 MP가 50이라 완전 재장전을 두 번 하면 MP가 바닥난다.** 이 상태에서는 파이어볼(MP 10)도 못 쓴다. 사격과 스킬이 같은 자원을 두고 다투는 것이 지금 설계의 의도이지만, **이 비율이 조정된 적은 없다.**

## 무기를 얻고 바꾸는 방법

| 경로 | 설명 |
|---|---|
| 시작 무기 | 게임 시작 시 자동으로 하나 지급 |
| 필드에서 줍기 | 방 바닥에 놓인 무기를 상호작용으로 습득 |
| 상자에서 나옴 | 보물 상자 내용물에 무기를 넣을 수 있다 (→ [[아이템 목록]]) |
| 카드 보상 | `소총 획득` 카드 (→ [[카드 목록]]) |

- **무기 슬롯은 2개**다. 1번과 2번 키로 교체하고, 교체 시 몽타주가 있으면 재생된다.
- 슬롯이 꽉 찬 상태에서 새 무기를 얻으면 **어느 것을 버릴지 고르는 화면**이 뜬다. 버린 무기는 바닥에 떨어져 다시 주울 수 있다.
- 무기는 **스택되지 않는다.** 같은 소총 두 자루도 각각 별개의 개체다.

## 아직 없는 것

| 없는 것 | 메모 |
|---|---|
| **근접 무기** | 무기 클래스 자체가 없다. 슬롯·교체·픽업 시스템은 무기 종류를 가리지 않게 만들어져 있어서, 근접 무기 클래스만 추가하면 나머지는 그대로 동작한다 |
| **근접 공격의 히트 판정** | 근접 콤보 애니메이션(1타/2타 구간 전환)은 있지만 **아무것도 맞지 않는다.** 트레이스도 콜리전도 없다 |
| **무기 다양성** | 산탄총, 기관총, 저격총 같은 변형이 전부 데이터 행 추가로 가능한데 행이 하나뿐이다 |
| **무기 등급/희귀도** | 같은 무기의 강한 버전이라는 개념이 없다 |
| **무기 고유 효과** | 데이터가 순수 수치뿐이라 "관통", "폭발" 같은 무기별 특수 동작을 표현할 자리가 없다 |
| **탄약 종류** | 탄약은 MP로만 표현된다. 별도 탄약 자원이 없다 |

## 미정

- 근접 무기가 원거리와 같은 슬롯을 쓰는가, 아니면 "주무기 + 근접" 형태로 별도 슬롯인가?
- 근접 무기도 MP를 쓰는가? 지금 MP 소모는 재장전에 묶여 있어서 근접에는 대응물이 없다.
- 무기 다양성을 수치(데미지·연사·탄창)만으로 낼 것인가, 아니면 무기마다 고유 동작(관통·산탄·차징)이 필요한가? 후자면 데이터 구조에 항목이 늘어난다.
- 완전 재장전 비용 MP 30이 최대 MP 50의 60%다. 사격과 스킬의 자원 경쟁 비율이 이대로 맞는가?
- 무기에도 등급/희귀도를 붙일 것인가? 카드에 희귀도 개념이 아직 없는 것과 같은 갈림길이다.
