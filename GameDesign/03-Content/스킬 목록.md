# 스킬 목록

키를 누르고 있으면 차오르고, 떼면 나간다. 지금 존재하는 스킬은 **파이어볼 하나**뿐이다.

> `DT_SkillData`에는 행이 하나(`Skill_Fireball`)만 있다. 아래 수치는 그 행의 실제 값이며 **임시 테스트 값**이다.

관련 문서: [[스킬]] · [[데미지 공식]] · [[카드 목록]] · [[레벨 곡선]]

## 스킬 슬롯

슬롯은 3개이고 **슬롯 하나가 키 하나**다.

| 슬롯 | 키 | 현재 |
|---|---|---|
| 0 | 우클릭 | 파이어볼(카드로 획득했을 때) |
| 1 | Q | 비어 있음 |
| 2 | F | 비어 있음 |

슬롯 번호와 키가 1:1이라 "어느 슬롯에 넣을까"는 곧 "어느 키에 놓을까"다. **슬롯 세 개를 채울 스킬이 아직 하나뿐이라, 교체 화면과 드래그 재배치는 만들어져 있지만 실제로 쓸 일이 거의 없다.**

## 스킬 데이터가 조절하는 것

스킬 하나는 데이터 표의 행 하나다. 각 항목이 게임에서 무엇을 바꾸는지:

| 항목 | 무엇을 조절하는가 |
|---|---|
| **MP 소모** | 손을 떼는 순간 빠지는 고정값. **차징을 얼마나 했든 똑같이 든다** |
| **쿨타임** | 손을 뗀 순간부터 세는 재사용 대기 시간(초) |
| **기본 데미지** | 차징 배율이 곱해지기 전의 데미지 |
| **사거리** | 이만큼 날아가면 구체가 스스로 사라진다 |
| **투사체 속도** | 구체가 날아가는 속도 |
| **차징 시간** | 최대 차징까지 걸리는 시간. **0이면 차징이 없고 누르는 순간 발사된다** |
| **최대 차징 배율** | 완전히 차징했을 때 곱해지는 배율. **크기와 데미지에 함께 곱해진다** |
| **기본 크기** | 차징 배율이 곱해지기 전 구체의 크기 배율 |
| **관통 수** | **추가로** 관통하는 적 수. 0이면 한 명만, 1이면 두 명, -1이면 무한 |
| 스킬 타입 | 발사형 / 지속형. **지속형은 미구현이라 고르면 경고만 뜬다** |
| 태그 | 어느 계열(불·공격 등)에 속하는지. 지금은 표시용 |
| 구체 클래스 / 아이콘 / 이름 / 설명 | 겉모습과 UI 표시 |

### 설계상 중요한 두 가지

- **MP와 쿨타임은 차징률에 비례하지 않는다.** 비례시키면 "약하게 여러 번 연타"가 최적해가 되고, 그걸 막으려면 쿨타임까지 같이 조정해야 해서 조절 변수가 둘로 늘어난다. 고정값이면 "한 번 쓸 때 최대한 차징한다"가 자연스러운 최적해가 된다.
- **차징 배율이 데미지와 크기에 동시에 곱해진다.** 오래 누를수록 세지기만 하는 게 아니라 **커져서 더 잘 맞는다.** 두 이득이 같은 배율에 묶여 있어 조절 손잡이가 하나로 유지된다.

## 파이어볼

| 항목 | 값 |
|---|---:|
| 이름 | 파이어볼 |
| 설명 | 꾹 누르면 더 크고 강해진다 |
| 타입 | 발사형 |
| MP 소모 | 10 |
| 쿨타임 | 3초 |
| 기본 데미지 | 40 |
| 사거리 | 2000 |
| 투사체 속도 | 1500 |
| 차징 시간 | 1.5초 |
| 최대 차징 배율 | 1.5배 |
| 기본 크기 | 0.5배 |
| 관통 수 | 0 (한 명만 맞음) |
| 태그 | `Tree.Fire` |

### 차징에 따른 실제 값

배율 = 1 + (최대 차징 배율 − 1) × 차징률. 파이어볼은 최대 배율이 1.5이므로 배율은 **1.0에서 1.5 사이**다.

| 누른 시간 | 차징률 | 배율 | 데미지(배율 적용 전) | 구체 크기 |
|---:|---:|---:|---:|---:|
| 0초 | 0% | 1.00 | 40 | 0.50 |
| 0.5초 | 33% | 1.17 | 46.7 | 0.58 |
| 1.0초 | 67% | 1.33 | 53.3 | 0.67 |
| 1.5초 이상 | 100% | 1.50 | 60 | 0.75 |

여기에 다시 **스킬 공격력**이 배율로 곱해진다 (→ [[데미지 공식]]). 레벨별 최종 데미지(치명타 제외, 적 방어력 0 기준):

| 플레이어 레벨 | 스킬 공격력 | 무차징 | 최대 차징 |
|---:|---:|---:|---:|
| 1 | 10 | 44.0 | 66.0 |
| 2 | 14 | 45.6 | 68.4 |
| 3 | 20 | 48.0 | 72.0 |
| 4 | 27 | 50.8 | 76.2 |
| 5 | 35 | 54.0 | 81.0 |

### 여기서 드러나는 문제

- **최대 차징이 무차징 대비 1.5배인데 1.5초를 기다려야 한다.** 그 시간에 소총으로 약 3.75발(약 62 데미지)을 쏠 수 있다. **지금 수치로는 차징이 손해에 가깝다.**
- **잡몹 체력이 100이라 최대 차징 파이어볼(66)로도 한 방에 못 죽인다.** MP 10과 쿨타임 3초를 쓰고도 잡몹 하나를 못 정리한다.
- **스킬 공격력 성장(10→35)이 최종 데미지에 미치는 영향이 작다.** 배율식이라 만렙에서도 데미지가 1.23배밖에 안 오른다.
- 관통이 0이라 여러 마리를 한 번에 치지 못한다. **구체가 커지는 이득이 실질적으로 없다.**

## 아직 없는 것

| 없는 것 | 메모 |
|---|---|
| **파이어볼 외의 스킬** | 슬롯 2개(Q·F)에 넣을 것이 없다. 입력 바인딩·교체 UI·드래그 재배치는 전부 완성돼 있다 |
| **지속형 스킬** | 장판·오라 같은 것. 데이터로 고를 수는 있지만 발사하면 경고만 뜬다 |
| **쿨타임 감소의 적용** | 플레이어에게 쿨타임 감소 스탯이 있지만 **어디에도 연결되어 있지 않다.** 스킬 쿨타임에 붙이는 것이 가장 자연스러운 첫 후보다 |
| **스킬 강화** | 같은 스킬을 여러 번 얻거나 카드로 강화하는 개념이 없다 |
| **스킬 연출** | 차징 중 구체가 커지는 것 외에 이펙트·시전 애니메이션·발사 사운드가 없다. 아이콘도 자리표시자 텍스처다 |
| **툴팁** | 인벤토리 스킬 칸에 마우스를 올려도 설명이 안 뜬다. 데이터에 설명이 있는데 화면 어디에도 안 쓰인다 |

## 미정

- 최대 차징 배율 1.5배가 차징 시간 1.5초를 정당화하지 못한다. 배율을 올릴 것인가, 차징 시간을 줄일 것인가, 아니면 차징에 관통이나 범위 같은 **다른 이득**을 붙일 것인가?
- 스킬 공격력 성장이 배율식이라 체감이 약하다. 스킬 데미지를 평타와 다른 방식(예: 스킬 공격력을 가산)으로 계산할 것인가?
- 슬롯 3개를 채울 스킬 구성은? 최소한 "단일 대상 / 광역 / 유틸(이동·방어)" 정도의 축이 정해져야 나머지 두 슬롯의 의미가 생긴다.
- 쿨타임 감소를 스킬 쿨타임에 붙일 때 상한을 둘 것인가? 상한이 없으면 쿨타임 0이 가능해진다.
- 지속형 스킬은 어떤 형태인가 — 바닥에 까는 장판인가, 플레이어를 따라다니는 오라인가?
- 스킬도 무기처럼 필드에서 줍거나 상자에서 나올 수 있는가, 아니면 카드로만 얻는가?
