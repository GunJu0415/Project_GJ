# 카드 목록

레벨이 오르면 카드 3장이 뜨고 반드시 하나를 고른다. 지금 카드 풀에는 **6장**이 있다.

> `DT_CardData`의 카드 6장은 **시스템 검증용 임시 데이터**다. 효과 종류(스탯 / 무기 / 스킬)를 하나씩 확인하려고 만든 것이라, 밸런스가 잡힌 카드 세트가 아니다. 아이콘도 전부 기존 텍스처를 빌려 쓴 자리표시자다.

관련 문서: [[카드 성장]] · [[레벨 곡선]] · [[스킬 목록]] · [[무기]]

## 카드 데이터가 조절하는 것

| 항목 | 무엇을 조절하는가 |
|---|---|
| **효과 종류** | 이 카드가 무엇을 주는가 — 스탯 보너스 / 무기 지급 / 스킬 지급 |
| **스탯 효과** | 효과 종류가 스탯 보너스일 때만 쓰임. **가산**과 **증가율** 두 묶음으로 나뉜다 |
| **무기 클래스** | 무기 지급 카드일 때 어떤 무기를 줄지. 비어 있으면 그 카드는 뽑기에서 제외된다 |
| **스킬 ID** | 스킬 지급 카드일 때 어떤 스킬을 줄지. 비어 있거나 없는 스킬이면 뽑기에서 제외된다 |
| **태그** | 이 카드가 속한 계열. 특정 계열을 밀어주면 그 태그가 붙은 카드가 더 자주 나온다 |
| **중복 가능 여부** | 끄면 한 번 고른 뒤 풀에서 **영구히** 빠진다. 무기·스킬처럼 두 번 받아도 의미 없는 것에 쓴다 |
| **가중치** | 뽑힐 확률. **0 이하면 절대 안 뽑힌다** — 카드를 잠시 꺼두는 용도로도 쓸 수 있다 |
| 이름 / 설명 / 아이콘 | 카드에 표시되는 것 |

### 가산과 증가율

스탯 효과는 두 종류로 나뉘고 계산식이 다르다.

```
실효 스탯 = (테이블 값 + 가산) × (1 + 증가율 합)
```

증가율은 **곱하지 않고 더한다.** +15% 카드 두 장이면 1.30배이지 1.3225배가 아니다. 밸런싱이 예측 가능해지고, 카드를 많이 먹었을 때 지수적으로 터지지 않는다.

## 현재 카드 6장

| 이름 | 효과 종류 | 하는 일 | 태그 | 중복 | 가중치 | 뽑힐 확률 |
|---|---|---|---|:---:|---:|---:|
| 튼튼함 | 스탯 | 최대 체력 **+5** (가산) | `Tree.Defense` | 가능 | 1.0 | 25% |
| 예리함 | 스탯 | 공격력 **+15%** (증가율) | `Tree.Offense` | 가능 | 1.0 | 25% |
| 날렵함 | 스탯 | 이동 속도 **+50** (가산) | `Tree.Agility` | 가능 | 1.0 | 25% |
| 급소 노리기 | 스탯 | 치명타 확률 **+5%p** (가산) | `Tree.Offense` | 가능 | 0.5 | 12.5% |
| 소총 획득 | 무기 | 소총을 하나 준다 | `Tree.Offense`, `Weapon.Gun` | **불가** | 0.3 | 7.5% |
| 파이어볼 | 스킬 | 파이어볼을 슬롯에 넣어준다 | `Tree.Fire` | **불가** | 0.2 | 5% |

뽑힐 확률은 가중치 합 4.0 기준이다. 다만 **뽑기는 비복원 추출**이라 한 장 뽑을 때마다 남은 카드로 합을 다시 계산한다 — 위 확률은 "첫 장이 이 카드일 확률"이고, 3장 중 어딘가에 들어올 확률은 이보다 훨씬 높다. 또 무기·파이어볼 카드는 한 번 고르면 풀에서 빠지므로 그 뒤로는 남은 4장만 돈다.

### 이 6장이 실제로 뭘 하는가

| 카드 | 레벨 1 기준 체감 |
|---|---|
| 튼튼함 (+5 체력) | 최대 체력 100 → 105. **거의 아무 일도 안 일어난다.** 적 공격 한 대가 10이니 반 대 분량 |
| 예리함 (+15% 공격력) | 공격력 10 → 11.5. 총알 데미지 16.5 → 16.7. **1.4% 증가.** 공격력이 배율로 들어가는 구조라 초반 체감이 거의 없다 |
| 날렵함 (+50 이동속도) | 600 → 650. 적(300)보다 이미 두 배 빨라서 추가 이득이 크지 않다 |
| 급소 노리기 (+5%p 치명타) | 0% → 5%. 치명타 배율이 2배라 기대 데미지 +5%. **위 셋보다 확실히 낫다** |
| 소총 획득 | 슬롯이 비어 있으면 두 번째 무기, 차 있으면 교체 선택 화면 |
| 파이어볼 | 이 게임의 **유일한 스킬**을 얻는 경로 |

**여섯 장 중 실질적인 힘의 차이를 내는 것은 급소 노리기 하나뿐이다.** 나머지 스탯 카드 셋은 값이 너무 작아서 "고르는 재미"가 아니라 "아무거나 고른다"가 된다. 검증용 데이터라 당연한 결과지만, 실제 카드 세트를 만들 때 가장 먼저 손봐야 하는 부분이다.

## 카드를 받는 시점

| 언제 | 상태 |
|---|---|
| 레벨업 | **동작함.** 유일한 카드 지급 경로 |
| 악마의 계약 아이템 사용 | **동작함.** 최대 체력을 지불하고 카드 선택을 산다 (→ [[아이템 목록]]) |
| 스테이지 클리어 / 보스 처치 | **없음.** 지급 함수는 열려 있고 부르기만 하면 되는데, 부를 진행 구조가 아직 없다 |

연속 레벨업(한 킬로 2~3레벨이 오르는 경우)은 **대기열로 처리된다.** 화면을 한 번만 띄우고 끝내면 보상을 잃기 때문에, 오른 레벨 수만큼 차례로 뜬다.

카드는 **런마다 초기화된다.** 죽으면 먹은 카드도 스탯 보너스도 전부 사라진다 (→ [[런 루프]]).

## 아직 없는 것

| 없는 것 | 메모 |
|---|---|
| **실제 카드 세트** | 6장은 검증용이다. 계열별로 의미 있는 선택지가 되려면 최소 수십 장이 필요하다 |
| **회복 카드** | 효과 종류에 "회복"이 없다. 필드 회복 아이템은 있지만 카드로는 못 한다 |
| **리롤 / 스킵** | 3장이 전부 마음에 안 들어도 반드시 하나를 골라야 한다 |
| **희귀도의 시각 표현** | 희귀도는 가중치로만 존재한다. 화면에서 흔한 카드와 귀한 카드를 구분할 방법이 없다 |
| **계열 밀어주기의 발동 주체** | 태그 가중치를 올리는 장치는 있지만 **콘솔 명령으로만 호출된다.** 직업 카드나 "먹은 카드 누적"이 붙어야 실제로 트리를 타는 느낌이 생긴다 |
| **선택지 수 증가** | 3장을 4장·5장으로 늘리는 자리는 뚫려 있지만 아무도 안 쓴다. 영구 강화가 생기면 여기 꽂힌다 |
| **시간제 버프 / 개별 해제** | 스탯 보너스는 누적만 된다. "10초 이동속도 +50" 같은 것을 표현할 수 없다 |
| **리스크/리턴 카드** | 값을 음수로 넣으면 "최대 체력 −20%, 공격력 +30%" 같은 카드가 지금도 만들어지지만 실제로 하나도 없다 |

## 미정

- 계열(트리)을 몇 개로 갈 것인가? 지금 태그는 `공격 / 방어 / 민첩 / 불` 넷인데 이게 최종 축인지 임시인지 안 정해졌다.
- 스탯 카드의 적정 크기는? 지금 +5 체력, +15% 공격력이 나란히 있는데 체감 차이가 열 배 이상 난다. 가산과 증가율 중 무엇을 기본으로 삼을 것인가?
- 카드 희귀도를 등급(일반/희귀/전설)으로 명시할 것인가, 지금처럼 가중치만 둘 것인가? 명시하면 시각 표현과 등급별 효과 크기 규칙이 따라온다.
- 리롤/스킵을 줄 것인가? 준다면 횟수는 런당 고정인가, 영구 강화로 늘리는가?
- 계열 밀어주기를 무엇이 발동시키는가 — 시작 시 고르는 직업인가, 같은 태그 카드를 먹을 때마다 누적되는가?
- 카드가 스탯 말고 **동작**을 바꿀 수 있어야 하는가? (예: "총알이 관통한다", "회피 시 잔상") 지금 데이터 구조로는 표현할 자리가 없다.
