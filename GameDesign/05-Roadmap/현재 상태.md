# 현재 상태

이 문서 하나만 읽어도 **지금 이 게임에서 무엇이 되고 무엇이 안 되는지** 알 수 있게 쓴다.
근거는 `Docs/DevGuide.md`(코드 현황)와 커밋 로그다. 계획과 우선순위는 [[백로그]], 큰 단계는 [[마일스톤]]을 본다.

기준 시점: 2026-08-22 (마지막 커밋 `DT_RoomSpawn에 회복방/보급방 행 추가`)

---

## 한 줄 요약

**한 판이 처음부터 끝까지 돌아간다.** 허브에서 런을 시작해 방 하나에서 싸우고, 죽으면 게임오버 화면을 거쳐 허브로 돌아온다.
그 안의 전투·성장·아이템은 대부분 실제로 동작한다. **없는 것은 "런에 구조를 주는 것"** — 던전 여러 방, 스테이지, 승리 조건, 그리고 앱을 껐다 켜도 남는 것(세이브)이다.

---

## 시스템별 상태

범례: **동작함** = 플레이로 확인됨 / **일부만** = 뼈대는 있으나 빠진 축이 있음 / **없음** = 미구현

### 코어 루프

| 시스템 | 상태 | 내용 |
|---|---|---|
| 런 루프 (허브 ↔ 전투) | 동작함 | 허브 포탈로 런 시작, HP 0 → 게임오버 화면 → 허브 복귀. `RebirthCount` 증가 |
| 회차 인계 규칙 | 없음 | `FItemData.bPersistAcrossRuns`는 필드만 있고 아무도 읽지 않는다. 지금은 레벨 재진입으로 **전부 초기화**된다 |
| 세이브 / 로드 | 없음 | `RebirthCount`가 앱 종료 시 0으로 돌아간다 |
| 승리 조건 | 없음 | 런은 **사망으로만** 끝난다 |
| 스테이지 진행 | 없음 | 보스방(`AGJBossRoom`) 자리만 훅으로 비어 있다 |

### 전투

| 시스템 | 상태 | 내용 |
|---|---|---|
| 이동 / 마우스 에임 / 카메라 | 동작함 | 커서 방향 회전 + 커서 쪽으로 당겨지는 탑다운 카메라 |
| 8방향 회피 | 동작함 | 방향별 몽타주 + 모션 워핑 |
| 원거리 무기 | 동작함 | 오브젝트 풀 투사체, 탄창/재장전, 총구 소켓 발사, 관통·크기 배율 |
| 근접 전투 | **일부만** | `Attack1`/`Attack2` 몽타주 섹션 점프만 있고 **히트 판정이 없다.** 근접 무기 클래스 자체도 없다 |
| 데미지 공식 | 동작함 | `UGJCombatStatics` 단일 소스. 공격력·방어력 경감·치명타까지 한 경로 |
| 치명타 표시 | 없음 | 터져도 화면에 안 보인다 (치명타 여부가 공격자 쪽에만 있음) |
| 적 AI | 동작함 | 비헤이비어 트리로 탐지 → 추격 → 근접 공격. 선딜(`AttackWindup`) 후 판정이라 헛스윙이 성립 |
| 적 종류 | **일부만** | 근접 잡몹 한 종류. 원거리 적·엘리트·보스 없음 |
| 사망 연출 | 없음 | `OnDeath` BP 이벤트가 비어 있고, 적 데스 몽타주는 사격 몽타주를 임시로 재사용 중 |
| GAS | 없음 | 모듈만 링크돼 있고 `GetAbilitySystemComponent()`는 항상 null |

### 성장

| 시스템 | 상태 | 내용 |
|---|---|---|
| EXP / 레벨업 | 동작함 | 적 처치로 EXP, 한 번에 여러 레벨이 올라도 보상이 안 사라진다(대기열) |
| 스탯 3층 구조 | 동작함 | 테이블 원본 / 보너스 / 실효값 분리. 콘솔 `GJAddBonus`로 시험 가능 |
| 카드 선택 | 동작함 | 레벨업 시 3장 가중 랜덤(비복원), 태그로 트리 밀어주기, 무기 교체는 2단계 화면 |
| 카드 리롤 / 스킵 | 없음 | 3장이 다 싫어도 하나는 골라야 한다 |
| 액티브 스킬 | **일부만** | 슬롯 3개(우클릭/Q/F), 차징 발사, 쿨타임·MP, HUD 아이콘까지 완성. **실제 스킬은 파이어볼 하나뿐**이고 `Persistent` 타입은 미구현 |
| `CooldownReduction` | 없음 | 스탯 필드만 있고 어디에도 연결 안 됨 (스킬 쿨타임이 첫 후보) |
| 영구 강화 | 없음 | 허브에는 런 시작 포탈 하나뿐 |

### 아이템 / 인벤토리

| 시스템 | 상태 | 내용 |
|---|---|---|
| 상호작용(E) 습득 | 동작함 | `IGJInteractable` 하나로 아이템·무기·포탈·상자가 전부 같은 경로 |
| 인벤토리 | 동작함 | 20칸, 스택, 드래그 교체, 더블클릭 사용, 자동 정렬 |
| 무기 슬롯 / 스왑 | 동작함 | 2슬롯, 클릭 장착 / 드래그 자리 교체, 스왑 중 입력 잠금 |
| 회복 아이템 | 동작함 | `AGJHealItem` — 줍는 즉시 HP/MP 회복 (인벤토리에 안 들어감) |
| 대가 지불 아이템 | 동작함 | `AGJDevilItem` — 최대 HP를 깎고 카드 선택을 준다. 못 낼 때는 아이템이 남고 로그로 이유를 남김 |
| 가격표 UI | 없음 | 대가형 아이템의 가격이 로그로만 보인다 |
| 화폐 / 상점 | 없음 | `AGJShopNPC` 자리만 결정돼 있다 |

### 던전 / 방

| 시스템 | 상태 | 내용 |
|---|---|---|
| 방 하나 (Task A) | 동작함 | `DT_RoomSpawn` 행대로 적·아이템·상자를 **매번 다르게** 채우고, 전멸시키면 출구가 열린다 |
| 그레이박스 방 | 동작함 | `AGJBoxRoom`이 파라미터로 바닥·벽·문을 생성 — 아트 없이 바로 플레이 |
| 방 역할 데이터 | 동작함 | 전투방 / 보물방 / 회복방(`Heal_Room`) / 보급방(`Devil_Room`) 행 존재 |
| 보물 상자 | 동작함 | 한 번만 열리고 내용물을 바닥에 원형으로 뿌린다 |
| 절차적 배치 (Task B) | 없음 | **방이 하나뿐이고 손으로 놓아야 한다** |
| 문 | **일부만** | 방에 북쪽 문 하나뿐. 열리는 연출 없이 블로커가 그냥 사라진다 |

### UI

| 시스템 | 상태 | 내용 |
|---|---|---|
| 플레이어 HUD | 동작함 | HP/MP 바, EXP 바와 레벨, 스킬 아이콘 3개(쿨타임 덮개 + MP 부족 틴트) |
| 적 체력바 | 동작함 | 머리 위 월드 위젯, 탑다운 각도 무관 |
| 인벤토리 창 | 동작함 | 아이템 / 무기 / 스킬 3페이지, Tab 개폐 |
| 카드 선택 화면 | 동작함 | 카드 3장 + 교체 대상 선택 2단계 공용 |
| 게임오버 화면 | 동작함 | 회차 표시 + 허브 복귀 버튼 |
| 쿨타임 표시 방식 | **일부만** | 시계방향 차오름이 아니라 위에서 아래로 걷히는 형태 (머티리얼만 만들면 C++ 변경 없이 교체) |
| 툴팁 / 연출 | 없음 | 스킬 설명 툴팁, 레벨업 팝업·사운드, 차징 이펙트가 전부 없다 |

## 지금 실제로 되는 한 판

```
허브 레벨
  └ 포탈에 E → 전투 레벨 로드
       └ 방 하나: 적 랜덤 스폰, 바닥 아이템, 확률로 상자
            ├ 원거리 무기로 사격 (근접은 판정이 없어 못 씀)
            ├ 우클릭 차징 파이어볼
            ├ 적 처치 → EXP → 레벨업 → 카드 3장 중 택1
            ├ 아이템 습득 / 상자 개봉 / 회복·악마 아이템
            └ 전멸 → 출구 블로커 사라짐 → (갈 곳이 없다)
       └ HP 0 → 2초 후 게임오버 화면 → 허브 복귀, RebirthCount++
```

**끝이 두 갈래가 아니다.** 방을 다 치워도 다음이 없고, 이길 방법도 없다. 이게 지금 가장 큰 구멍이다 → [[백로그]] P0.

## 최근 개발 흐름

커밋 로그 기준. 시기별로 한 덩어리씩 끝내고 다음으로 넘어가는 패턴이다.

| 시기 | 한 일 |
|---|---|
| 07-29 ~ 08-01 | 프로젝트 초기화, 캐릭터·카메라·이동·구르기 |
| 08-04 ~ 08-08 | 무기/투사체 C++ + 오브젝트 풀링, 재장전, 데이터 테이블, 간단 AI, 인벤토리, 무기 장착 |
| 08-11 ~ 08-12 | **[[마일스톤\|M1]] 런 루프** — 허브 레벨, 게임오버, 런 시작 포탈. 이어서 전투 스탯과 데미지 공식 |
| 08-12 ~ 08-13 | **M2 EXP/레벨업** → **M2.5 스탯 보너스 3층 구조** → **M2.6 카드 선택** 착수 |
| 08-17 ~ 08-18 | 카드 선택 완성, **M2.7 액티브 스킬**(차징·슬롯·쿨타임) + 스킬 HUD/인벤토리 페이지 |
| 08-18 ~ 08-20 | **룸 시스템 Task A** — 방 골격, 적 스폰, 출구 개폐, 아이템·상자 |
| 08-20 ~ 08-22 | **A2 습득 아이템 종류** — 회복 아이템, 악마 아이템, 회복방·보급방 데이터 행 |

## 임시 값으로 굴러가는 것

밸런스 문서를 쓸 때 **이것들은 확정치가 아니다.** ([[레벨 곡선]], [[데미지 공식]] 참고)

- `DT_CharacterStat` 레벨 2~5 성장 곡선 — 스테이지 진행이 생긴 뒤에 잡아야 의미가 있다
- `DT_SkillData`의 파이어볼 수치, `SkillPower` 곡선
- `DT_CardData`의 카드 6장 — 검증용
- `DT_RoomSpawn`의 `Combat_Basic` 행
- 아이콘·초상화·스킬 아이콘이 전부 자리표시자 텍스처
