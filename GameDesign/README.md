# Project_GJ 기획 볼트

이 볼트는 **Project_GJ가 어떤 게임인지, 왜 그렇게 만들어졌는지**를 적어 둔 곳이다. 옵시디언으로 열어 읽는 것을 전제로 하고, 문서끼리는 위키링크로 이어져 있다.

## 이 볼트는 코드 문서가 아니다

| | `Docs/DevGuide.md` | `GameDesign/` (여기) |
|---|---|---|
| 답하는 질문 | 코드가 **어떻게** 돼 있나 | 게임이 **무엇이고 왜** 그런가 |
| 읽는 사람 | 코드를 고치려는 사람 | 게임을 설계·밸런싱·기획하려는 사람 |
| 담는 것 | 클래스·함수·델리게이트·함정 | 규칙, 의도, 콘텐츠, 미정 사항 |
| 안 담는 것 | 왜 그런 게임인지 | 클래스명 나열, 구현 세부 |

구현 세부가 필요하면 DevGuide로 간다. 반대로 "이 수치가 왜 이 값인가", "이 시스템이 무엇을 위해 있는가"는 여기서만 답한다.

## 이 볼트의 규칙 두 가지

**근거 없는 것은 쓰지 않는다.** 여기 적힌 것은 전부 소스, 설계 문서(`Docs/superpowers/specs/`), 데이터 테이블에서 확인된 것이다.

**안 정해진 것은 지우지 않고 남긴다.** 각 문서 맨 아래 `## 미정` 섹션에 **질문 형태로** 적는다. 무엇이 아직 안 정해졌는지 한눈에 보이는 것이 이 볼트의 값어치다. 자세한 것은 [[문서 작성 규칙]] 참고.
